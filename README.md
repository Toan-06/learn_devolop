# D-Quiz A1 - Thi Bằng Lái Xe Máy

Ứng dụng thi bằng lái xe A1 với 250 câu hỏi, hình ảnh biển báo giao thông thật.

## Live Demo

🔗 **https://d-quizz.vercel.app**

## Tính năng

- ✅ 250 câu hỏi thi bằng lái xe A1
- ✅ Hình ảnh biển báo giao thông thật
- ✅ 6 danh mục: Luật giao thông, Biển báo, Tốc độ, Xử phạt, Kỹ thuật, Văn hóa
- ✅ Đếm ngược thời gian 30 phút
- ✅ Giải thích đáp án chi tiết
- ✅ Bộ lọc theo danh mục
- ✅ Responsive - đẹp trên mọi thiết bị

## Deploy

```bash
npm install -g vercel
vercel
```
